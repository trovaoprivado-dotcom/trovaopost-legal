Privacy Policy — TrovãoPost

TrovãoPost runs locally on the user's machine and does not operate a centralized remote database to store third-party personal data.

API keys and OAuth tokens (such as TikTok access/refresh tokens and Gemini API keys) are stored locally in the user's environment/configuration files to authenticate requests to official APIs.

Users can revoke TikTok access at any time directly through their TikTok account security/app permissions settings.
